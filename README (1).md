# SMS Spam Collection — Pandas Data Cleaning

This project cleans the UCI SMS Spam Collection dataset.

## Files
- `SMS_Spam_Cleaning.ipynb` — step-by-step cleaning notebook.
- `cleaned_sms.csv` — generated by running the notebook.
- `requirements.txt` — Python dependencies.

## Run
```bash
pip install -r requirements.txt
jupyter notebook SMS_Spam_Cleaning.ipynb
```
Run every cell from top to bottom. The notebook downloads the original UCI dataset and generates `cleaned_sms.csv`.

## Dataset citation
Almeida, T. & Hidalgo, J. (2011). SMS Spam Collection. UCI Machine Learning Repository. https://doi.org/10.24432/C5CC84. Licensed under CC BY 4.0.
